# 🎬 Movie Explorer

A modern and responsive movie and TV show discovery web application built with **React**, **Tailwind CSS**, and the **TVMaze API**.
Movie Explorer allows users to browse TV shows, search for specific shows, and view detailed information through an interactive modal.

## 📌 Features

- 🎬 Browse TV shows from the TVMaze API
- 🔎 Search for TV shows
- 🖼️ Display show posters and information
- ⭐ Display show ratings
- 📅 Display premiere year
- 🎭 Display genres
- 📖 View detailed show information
- 💬 Interactive details modal
- 📱 Fully responsive design
- ✨ Modern UI with smooth hover and transition effects
- 🧭 Client-side routing with React Router

## 🛠️ Technologies Used

- React.js
- Tailwind CSS
- React Router DOM
- TVMaze API
- Lucide React
- Vite
- JavaScript (ES6+)
